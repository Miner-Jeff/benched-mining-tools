# Support and bug reports

* Bugs can be reported through the GitHub **Issues** tab using the bug report form. Include the plugin version, your QGIS version, and the full log text.
* This is a free, volunteer-run, experimental project. **There is no guarantee that any report will be answered or that any bug will be fixed**, and no timeline or service level applies.
* The software is provided without warranty and is used entirely at your own risk (see `LICENSE`). It is a planning aid, not engineered mine design.
* Pull requests are welcome but may not be reviewed or merged.
